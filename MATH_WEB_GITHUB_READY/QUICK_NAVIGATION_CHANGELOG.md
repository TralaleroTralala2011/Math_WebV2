# Điều hướng nhanh MATH_WEB

- Thêm ba nút nổi cố định ở góc dưới phải: Lộ trình học (trên cùng), Vẽ hình (giữa), Học bài (dưới cùng).
- Gỡ liên kết Lộ trình học cũ khỏi thanh điều hướng ở các trang được cập nhật.
- Chia sẻ CSS và JavaScript, hỗ trợ màn hình nhỏ, bàn phím và reduced motion.
- Không thay đổi logic học tập, đăng nhập hoặc backend.
- Chưa kiểm thử trình duyệt thực tế.
